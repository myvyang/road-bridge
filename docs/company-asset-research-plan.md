# 公路上市公司与路产采集计划

更新时间：2026-07-27

## 目标

这个项目的数据顺序固定为：

1. 先确认上市公司池。
2. 再从公告和年报中抽取公司拥有、经营、参股或受托管理的路产资产。
3. 每条路产建立独立台账。
4. 最后把已确认路产标到地图。

公开网页以“路产”为主维度，不展示研究备注、核验状态和待补字段。内部采集表保留来源、页码、披露口径和字段状态。

## 优先级口径

后续优先分析“通行费更纯、披露更清楚”的公司。排序时不用法定营业收入直接做分母，而是先剔除与自身特许经营资产建设、改扩建相关的建造服务收入和成本：

```text
调整后经营收入 = 营业收入 - 自身特许经营资产建造服务收入
通行费纯度 = 通行费收入 / 调整后经营收入
```

建造服务应单列到资本开支、在建项目、特许经营资产或投资现金流桥表，不作为路产经营收入。对外工程施工、机电工程、运营服务等第三方业务不能自动剔除。

经营事件也按重要性筛选：收入、成本、毛利、车流或资本开支影响低于 20% 的短期扰动，默认不进入主报告；影响收费期限、资产归属、并表范围、REITs、政府回购或重大减值的事件必须保留。

## 单条路产字段基准

每条路产必须按同一套字段采集：

- 基础：资产名称、路线编号、起点、终点、省份、收费里程、车道数、开通时间。
- 权属：上市公司、直接持有主体、持股比例、控股/参股/受托管理、是否合并报表。
- 收费权：收费起始日、收费截止日、剩余年限、收费性质、收费批复文件。
- 投资：建造成本、改扩建概算、收购成本、资本金比例、累计投入。
- 运营：年度通行费收入、日均车流、车型结构、货车占比、养护/施工/分流说明。
- 关系：相邻路产、替代路产、同一走廊、改扩建影响、已停止收费或政府回购。
- 来源：公告标题、公告日期、披露页码、URL、字段状态。

## 数据结构建议

后续不要继续把所有东西塞进 `app/data/roadAssets.ts`。建议拆成三层：

- `companies.json`：上市公司静态信息。
- `assets.json`：公开展示的路产事实，只放可展示字段。
- `research-ledger.json` 或独立 CSV：来源、页码、核验状态、待补问题，不进公开页面。
- `asset-relations.json`：路产之间的相邻、替代、同走廊、股权交叉关系。

等字段稳定后，再考虑迁移到 SQLite/Postgres；现阶段静态 JSON 更适合 GitHub Pages。

## 采集顺序

1. 先做第一层公司池，逐家公司保存最近一期年报 PDF 和公告链接。
2. 每家公司先抽“路产名称、权益比例、收费里程、收费截止日”四个高价值字段。
3. 对字段齐全的路产先上地图；缺收费期限或权益比例的路产先进入股票页资产清单，不画线路。
4. 地图几何先按路线关键节点手工打点，统一转为 GCJ-02；不要抓未授权地图矢量。
5. 每完成一家公司，跑一次页面构建测试，再发布。

## 当前样板

楚天高速已作为第一家公司样板入库：

- 公开资产数据：`app/data/assets.json`
- 公开公司数据：`app/data/companies.json`
- 内部来源台账：`data/research-ledger.json`

这家公司适合作为模板，因为 2025 年报同时披露了收费项目表和分地区收入成本表。需要注意两处披露口径：

- 汉宜高速的收入和成本按汉宜高速合并披露，收费期限表拆为汉荆段、江宜段。
- 黄咸高速的收入和成本按黄咸高速合并披露，收费期限表拆为咸宁段、黄石段。
