# 路桥资产地图

这是一个面向路桥 / 高速公路股票研究的地图网站原型。目标不是只筛选股票，而是把单条公路、桥梁、收费权、归属公司和相邻通道关系放到地图上看。

## 当前能力

- 地图展示多条高速路产线路。
- 搜索路段、公司和股票代码。
- 点击路段后查看归属公司、证券代码、收费期限、建设 / 收购成本、开通时间、通行量、货车占比和风险备注。
- 显示相邻或同一走廊路产关系。
- 所有样例数据都显式标记为 `样例` 或 `待核验`，避免误当成研究结论。

## 数据原则

路桥公司本质上是收费权资产组合。公司层面的利润和现金流只能回答一部分问题，正式研究需要按单条路产建立台账：

- 建设费用或收购成本。
- 收费起止日、收费年限和剩余年限。
- 开通时间和改扩建节点。
- 历年单路收入、利润、车流、货车占比。
- 施工、分流、政策调整、收费权续期和政府回购安排。
- 年报合并披露时必须保留“合并披露”状态，不能强行拆分。

## 项目结构

- `app/components/RoadAssetExplorer.tsx`：地图和路产信息工作台。
- `app/data/roadAssets.ts`：第一版路产样例数据和字段模型。
- `docs/data-model.md`：后续真实数据入库模型。
- `project-memory/`：长期开发判断和当前状态。
