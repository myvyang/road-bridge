# 项目概览

`road_bridge` 是路桥 / 高速公路股票研究的地图网站。项目方向来自 `stock_analysis` 中对通行服务类公司的研究经验：不能只看公司层面利润，必须拆到单条路产和收费权资产。

## 目标

- 先维护上市路桥公司清单，再维护公司下面的路产资产，最后把路产资产标到地图。
- 在地图上浏览高速公路、桥梁和城市快速路。
- 查看每条路产的归属公司链接、收费期限、剩余年限、建设或收购成本、开通时间、通行量和货车占比。
- 显示路产之间的相邻、同一走廊、同一公司和分流关系。
- 为每个股票提供独立资产清单页；股票页不带地图，点击路产回到地图选中该路。
- 后续把年报、公告、收费权批复和运营披露作为可追溯数据源。
- 中国大陆地图底座使用高德优先，路产几何统一按 GCJ-02 `[经度, 纬度]` 维护。
- 发布目标是 GitHub Pages：`https://myvyang.github.io/road-bridge/`。

## 边界

- 当前第一版是可交互地图原型，内置样例数据。
- 地图页主维度是路产，不是股票；股票只是路产详情里的归属链接。
- 样例数据不能作为投资研究结论。
- 正式数据入库前，关键字段都需要来源链接和披露口径。
- 未配置地图 Key 时页面可以使用本地兜底路线图，但这不代表真实底图或路网已经接入。
- GitHub Pages 是静态站托管，不能依赖服务端 API、Worker、D1 或运行时 SSR。
