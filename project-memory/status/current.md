## 当前限制

- 楚天高速已完成公告级字段样板，但路线几何仍是人工维护的走廊级折线，不是授权路网矢量。
- 既有非楚天公司资产仍是原型数据，后续需要按同一模板逐家公司替换为公告级数据。
- 当前网页还没有展示“公司整体财报 - 路产披露单元 - 差额解释 - 单路资产卡片”的完整勾稽表，这一层先在文档中验证。
- 本地兜底底图只能保证页面可用，不替代真实地图底图和精确路网数据。
- 高德真实底图需要在运行环境配置 `NEXT_PUBLIC_AMAP_KEY`，必要时还需要 `NEXT_PUBLIC_AMAP_SECURITY_CODE`。
- 收费期限、建设成本、开通时间、单路收入和运营指标需要逐条追溯来源；来源状态只进入内部采集台账。
- 年报合并披露的收入和利润后续需要保留披露范围，不能强拆。
- 生产环境真实高德底图仍依赖 GitHub Actions secrets 中的 `NEXT_PUBLIC_AMAP_KEY`。
