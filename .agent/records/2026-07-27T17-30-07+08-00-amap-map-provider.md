## Engineering Context

The previous map failure was not only a CSS problem. For China road assets, the map provider and coordinate system must be treated as core data-model choices. The project now standardizes on GCJ-02 for mainland route geometry and uses AMap as the first real basemap provider. WGS84/GPS points must be converted before display; BD-09 data should not be mixed unless the project intentionally switches to Baidu.

The local fallback route layer is only a continuity tool for development and for missing credentials. It is not a substitute for real domestic basemap tiles or verified road geometry.
