## Engineering Context

The screenshot showed a product-structure problem, not only a CSS issue: large controls were placed inside the map canvas and competed with the map. The durable rule is that the map canvas should stay visually clear; selection/search controls belong in a sidebar or separate inventory page.

The gray map also showed that external raster tiles are not reliable enough as the only visual base. This version keeps Leaflet routes and OpenStreetMap tiles, but adds a local visual fallback under the Leaflet layer.

## Open Questions And Risks

- The fallback map is only a visual scaffold. A production version still needs a reliable map tile source or locally hosted vector tiles for precise road discovery.
